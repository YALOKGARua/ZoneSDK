# ZoneHelloHud, зразок 1 для ZoneSDK

Невеликий аддон, що малює в куті екрана панель із позицією гравця (X, Y, Z у метрах), напрямком за компасом і швидкістю по землі. Його варто читати: кожен файл показує одну частину того, як пишуть аддон на ZoneSDK. Постачається лише у вигляді вихідного коду.

## Що показано, файл за файлом

| Файл | На що дивитися |
| --- | --- |
| `src/hellohud.h` | Таблиця дієслів: `verbs::Join(common::kWorld, kOwn)` ставить спільний каталог світу першим, тому `WorldVerbs{}` не потребує індексів. Власні дієслова: рядки `verbs::Spec` з позначеними ініціалізаторами для трьох функцій `Actor`, доступних через рефлексію: `K2_GetActorLocation` (обов'язкова), `GetVelocity` і `K2_GetActorRotation` (необов'язкові; у Blueprint останні дві звуться GetVelocity і GetActorRotation). Налаштування, наказ і опублікований `Status`. |
| `src/app.cpp` | `App`, зібраний позначеними ініціалізаторами: ідентичність, типова політика, статичні класи для перепису, рядок таблиці ZoneSDK з тегом, смугою підказок і типовою клавішею. |
| `src/settings.cpp` | Схема ini: `language` (auto, uk, en; auto бере мову гри), прапорці, `ini::Choice` для кута екрана і одиниці швидкості, клавіша, записана назвою. |
| `src/frame.cpp` | Хук кадру. Він ніколи не викликає гру: на клавішу він викликає `thread::Ask(Order::Toggle)`, а SDK виконує наказ у потоці гри. |
| `src/core.cpp` | Потік гри: `Order` перемикає панель і зберігає це, `Step` кожні 100 мс читає три значення через `Call` і `Fire` (кожен виклик за першого разу несе свою мітку збою), `Hot` тримає помпу активною лише тоді, коли панель показано у стабільному світі, `Publish` копіює стан під м'ютексом, а `Snapshot` віддає копію стороні малювання. `Section` додає рядок до тексту «Скопіювати звіт». |
| `src/view.cpp` | Чисті функції без гри і без ImGui: напрямок (північ — це -Y), сторона світу, швидкість, рядки українською чи англійською, розміщення в куті. Їх перевіряє `tests/local.cpp`. |
| `src/overlay/corner.cpp` | Хук оверлею: `paint::Box`, `paint::Corners` і `paint::Text` на передньому списку малювання, шрифт, що малює кирилицю, палітра з `paint::ink()`. |
| `src/overlay/page.cpp` | Вкладка ReShade: мова, прапорці, вибір кута екрана і одиниці швидкості, `tab::KeyField` для клавіші, живі рядки, підказки через `Words` і `Tone`, і `tab::Diagnostics(o)` з типовими текстами SDK. |
| `src/lang_rows.cpp` | Рядки UA і EN; типові рядки SDK заповнюють тексти діагностики і клавіші. |
| `tests/local.cpp` | Збереження і читання налаштувань, клавіша, рядок таблиці ZoneSDK, таблиця дієслів, компас, рядки, кути екрана, наказ перемикання, збережений ini, публікація і знімок з другого потоку. |

Сира пам'ять гри не читається: значення надходять лише з функцій, доступних через рефлексію, і аддон не має `guard::Field`. У коді немає коментарів, а `tests/zsdk.cfg` вмикає перевірку цього рядком `comments=forbid`.

## Збирання і перевірка

З розпакованої теки ZoneSDK, у `samples\ZoneHelloHud`:

1. `.\test.cmd`: збірка Release і тести. `build\zsdk.lock` закріплює випуск ZoneSDK із цього пакета, а `build\make.ps1` сам знаходить `release\<версія>`.
2. `.\fakehost.cmd -Addon samples\ZoneHelloHud\bin\ZoneHelloHud.addon64 -Label hellohud -All` з теки ZoneSDK: прогони без гри.
3. `.\build.cmd -Tests -Verify`: тести ще раз і перевірки готового файлу. Після збирання без `-Tests` `pack.cmd` попереджає, що файл зібрано без успішних тестів.
4. `.\pack.cmd`: пише `dist\ZoneHelloHud-<версія>.zip` з описами для гравця з `dist\`.

У грі панель видно лише у світі гри, після завантаження збереження; ALT+7 показує або ховає її, а вкладка працює всюди.

## Власний аддон

Новий аддон починайте з `new-addon.cmd`, який пише свіжі тег, клавішу, смугу і `zsdk.lock`, а звідси беріть потрібні частини. Не випускайте цей зразок з його тегом ZoneHelloHud: два аддони з одним тегом ніколи не завантажуються разом, а `new-addon.cmd` відхиляє назву і тег зразка.
